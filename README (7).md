## 📐 Convenciones visuales

- **Color primario:** `#1A1A2E` (azul oscuro / negro deportivo)
- **Color secundario:** `#E94560` (rojo energético)
- **Color acento:** `#F5A623` (naranja vibrante)
- **Tipografía:** Bebas Neue (títulos) + Roboto (cuerpo)
- **Iconos:** Bootstrap Icons
- **Espaciado:** sistema de Bootstrap (`p-3`, `m-2`, etc.)
- **Grid:** Bootstrap 5 — `col-12 col-md-6 col-lg-4` para responsive
